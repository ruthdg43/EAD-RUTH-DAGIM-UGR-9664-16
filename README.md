
# LAB 1 : JAVA MAVEN STARTER PROJECT

## About

This is my Java project. It connects Java to a MySQL database using JDBC and Maven.

The program connects to the `StudentsDB` database and displays student information from the `students` table.

## Tools Used

- Java
- MySQL
- JDBC
- Maven
- Eclipse

## Output

The program displays the students' IDs, names, and grades.
